# Dota Build Daily — logo guidelines

**The idea:** six item tiles, the six inventory slots every answer fills, assemble into a **D**.
The green tile is the slot you got right. *The build is the brand.*

All artwork is generated by `brand/src/build.py` (masters) and `brand/src/export.py` (PNGs, web
icons). Change the geometry there, never by hand; the game and the Discord results card read the
same shapes from `src/brand/mark.ts`.

Pantone references (closest, check against a physical guide before printing): Gold ≈ 7563 C,
Green ≈ 7739 C, Ink ≈ Black 6 C.

The brand colours are fixed: colour-blind mode in the game remaps tile *states*, never the logo.

## Type

Wordmark: **Big Shoulders Display ExtraBold**, all caps, +2 % tracking, converted to outlines
(SIL Open Font License, so logo use is allowed). UI text in the game uses Sofia Sans.

## Clear space and minimum size

- Keep clear space of **one tile width** (¼ of the symbol's width) on every side.
- Symbol: minimum **16 px** on screen (use the small cut below 40 px), **8 mm** in print.
- Horizontal lockup: minimum **120 px** wide; below that use the symbol alone.

## Backgrounds

- Primary: gold/green on Ink. On light greys and white, use the light version (Ink tiles).
- On photos or busy art, put the mark on an Ink tile.
- One-colour black or white only when colour isn't available (embroidery, single-colour print).

## Don't

- Recolour the tiles individually, or swap which tile is green.
- Rearrange, rotate, add or remove tiles; it must stay six tiles forming a D.
- Add gradients, outlines, glows or shadows.
- Stretch the lockup or set the name in another font.
- Use Valve or Dota 2 artwork next to the mark as if it were part of it.

## Notes
